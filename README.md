# instagram-followers-scraper
Fitur utama:
 - Auto scrape IG followers

 ---------------------------------------------------------------
 Install Package pendukung di Ubuntu:
  - sudo apt update
  - sudo apt install -y nodejs npm
  - npm init -y
  - npm install playwright
  - npx playwright install chromium chrome

  Cara menjalankan di Ubuntu:
  - node followers_scraper.js
